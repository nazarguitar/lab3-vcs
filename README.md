Файл TESTING.md містить рекомендації для ручного тестування програми. Він допомагає послідовно перевіряти запуск, коректні та некоректні вхідні дані, очікувані результати й виправлення помилок.

Використання: відкрий TESTING.md і послідовно виконуй наведені перевірки під час тестування проєкту.

## Синхронізація репозиторію

- `git fetch origin` завантажує інформацію про нові коміти без інтеграції.
- `git diff main origin/main` показує відмінності між локальною та віддаленою гілками.
- `git pull --ff-only` оновлює локальну гілку лише за можливості fast-forward.
- `git status` показує поточний стан робочої папки.
