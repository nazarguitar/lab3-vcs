# Пам’ятка тестувальника

## Основні правила тестування

1. Перевір, що програма запускається без помилок.
2. Використовуй коректні вхідні дані для перевірки основних функцій.
3. Перевіряй поведінку програми на порожніх або некоректних даних.
4. Порівнюй фактичний результат з очікуваним.
5. Записуй кожну помилку, додаючи кроки відтворення та очікуваний результат.
6. Повторюй перевірки після виправлення помилок.
7. Перед завершенням тестування переконайся, що основні функції працюють правильно.
